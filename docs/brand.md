# 폴룸 브랜드 가이드

## 이름과 약속

- 한국어 이름: 폴룸
- 영문 이름: Foloom. 문장에서는 첫 글자를 대문자로 씁니다.
- 로고 워드마크: 소문자 `foloom`
- 명령·저장소·패키지 식별자: `foloom`
- 슬로건: 같은 문서에서, 함께.
- 제품 설명: 사람과 AI가 함께 일하는 문서 공간

Folio와 Loom을 연결한 조어입니다. 사람과 AI의 작업을 하나의 문서로 엮는다는
이야기를 담습니다. 자동 완성만이 아니라 사용자가 변경과 저장 상태를 확인하면서
함께 작업하는 제품입니다. 현재 XLSX 비공개 알파와 DOCX 실험 범위를 정확하게
안내하며, 계획 중인 형식이나 native Office 호환성을 이미 제공한다고 표현하지 않습니다.

## 심볼과 워드마크

![폴룸 워드마크](brand/foloom-wordmark.svg)

두 직각 리본이 교차해 F를 만듭니다. 소나무색은 사용자가 유지하는 문서의 구조,
테라코타는 작업에 더해지는 AI의 흐름을 표현합니다. 장식적인 반짝이, 로봇,
파일 확장자를 심볼에 넣지 않아 문서 종류가 늘어나도 같은 브랜드를 사용합니다.

| 자산 | 용도 |
| --- | --- |
| [컬러 심볼](brand/foloom-symbol.svg) | 제품 헤더, 작은 표시 |
| [단색 심볼](brand/foloom-symbol-mono.svg) | 단색 인쇄, 제한된 색상 |
| [역상 심볼](brand/foloom-symbol-inverse.svg) | 어두운 배경 |
| [워드마크](brand/foloom-wordmark.svg) | README, 제품 소개 |
| [역상 워드마크](brand/foloom-wordmark-inverse.svg) | 어두운 배경의 소개 |
| [앱 아이콘](brand/foloom-app-icon.svg) | favicon, 저장소 아이콘용 원본 |
| [소개 이미지](brand/foloom-social.svg) | 1280×640 공유·저장소 소개용 원본 |

[소개 이미지 PNG](brand/foloom-social.png)와 [512px 앱 아이콘 PNG](brand/foloom-app-icon.png)도
제공합니다. SVG가 편집 가능한 원본입니다. 워드마크는 시스템 sans-serif fallback을 사용하며
외부 글꼴 파일·네트워크 요청을 요구하지 않습니다. 제품은 같은 심볼 원본을
빌드에 포함합니다. favicon은 SVG를 내장하여 MCP App에서도 독립적으로 표시합니다.

심볼은 24px 이상, 워드마크는 100px 이상을 권장합니다. 외곽에 심볼 폭의 1/4
이상을 비우고, 비율·교차 순서를 바꾸거나 효과·그라데이션을 덧붙이지 않습니다.
어두운 배경에는 역상을 사용합니다. 접근성 이름은 `폴룸 Foloom`으로 제공하고
중복된 장식 심볼은 보조 기술에서 숨깁니다.

## 색상과 글자

| 역할 | 색상 | 사용 |
| --- | --- | --- |
| 소나무 | `#234A45` | 로고, 주요 제목 |
| 동작 | `#315C50` | 기본 버튼, 키보드 포커스 |
| 테라코타 | `#C57553` | 심볼의 작은 강조 |
| 종이 | `#F6F4EF` | 작업 공간 배경 |
| 잉크 | `#22302E` | 기본 텍스트 |
| 흰색 | `#FFFFFF` | 도구, 카드, 문서 용지 |

작은 본문이나 버튼의 흰 글자 배경에는 충분히 어두운 소나무 계열을 사용합니다.
테라코타는 작은 텍스트나 오류 색으로 사용하지 않습니다. 실패·충돌의 적색과
확인 필요 상태의 황색은 의미를 유지합니다. 색만으로 상태를 전달하지 않습니다.

앱은 Inter, Pretendard, Noto Sans KR, system-ui 순서의 로컬 글꼴을 사용합니다.
제목은 절제된 굵기, 본문은 읽기 쉬운 크기, 동작 대상은 최소 44px를 유지합니다.
새 글꼴 다운로드는 추가하지 않습니다. 사용자 문서에 저장된 글꼴·색·셀 서식은
앱 브랜드 팔레트로 바꾸지 않습니다.

## 제품에서의 적용

- 작업 공간 헤더에는 워드마크, 빈 화면에는 심볼·슬로건·현재 지원 형식을 표시합니다.
- XLSX·DOCX 헤더에는 작은 심볼과 실제 문서명·저장 상태를 우선합니다.
- 도구와 시트는 기존 엔진 경계를 유지하며 앱 강조색만 통일합니다.
- 한국어·영어·일본어·중국어 간체로 제품 소개를 표시하고 사용자 내용은 번역하지 않습니다.
- 모션 감소, 키보드 포커스, 터치 대상, 작은 화면에서 문서 작업을 유지합니다.

## 문구 원칙

짧고 구체적으로 안내합니다. 저장 대기·확정·실패·충돌을 명확히 구분하고,
AI 작업을 확인하지 않았는데 완료로 표현하지 않습니다. '완벽한 호환', '무손실',
'모든 문서 지원'처럼 근거 없는 표현을 사용하지 않습니다.

브랜드 자산은 공개 소스 저장소의 제품 자산입니다. 소스 라이선스는 상표 등록,
도메인 소유, 상표 권리 양도 또는 공식 제휴를 뜻하지 않습니다.
